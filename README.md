# QApp

Turn any website into a standalone desktop app.

## Features

- Install any website or PWA as a native-feeling desktop app
- File downloads with save-as dialog — choose filename and folder every time
- Per-app profiles, cookies, and cache (apps are fully isolated)
- Scope-aware navigation (out-of-scope links open in system browser)
- W3C PWA support: manifest, display modes, push notifications, badging, offline indicator
- Resume overlay — no black screen when switching desktops

## Install

```bash
git clone https://github.com/QAppFramework/QApp.git
cd QApp
bash install.sh
```

## Requirements

- Linux (KDE/GNOME)
- Qt 6.5+ (qt6-base-dev, qt6-declarative-dev, qt6-webengine-dev)
- cmake, g++
